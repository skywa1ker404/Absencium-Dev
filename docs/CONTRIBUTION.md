Contributing to Absencium

Thanks for your interest in Absencium!

Absencium is an Android-focused student companion project. Contributions, bug reports and thoughtful suggestions are welcome.

Before contributing

- Check existing issues before opening a duplicate.
- Explain the problem your change solves.
- Keep changes focused and easy to review.
- Follow the existing Kotlin and Jetpack Compose conventions.
- Avoid unrelated changes to the app's architecture or design.

Reporting bugs

Open an issue at:

https://github.com/skywa1ker404/Absencium/issues

Include reproduction steps and relevant logs when possible. Remove passwords, API keys, personal information and private academic records before sharing logs.

Suggesting features

Describe the problem, your proposed solution and any relevant use cases. Features may be accepted, revised or declined depending on the project's goals.

Pull requests

1. Fork the repository.
2. Create a branch for your change.
3. Make and test your changes.
4. Explain the changes in your pull request.
5. Wait for review before assuming a change has been accepted.

Please be respectful and constructive.

Thank you for helping make Absencium better!
