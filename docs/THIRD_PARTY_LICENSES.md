# Third-party licences

This file credits what Absencium uses that it did not write. Every licence named here was read from the component's own
LICENSE file, its embedded metadata or its published POM; nothing is listed from memory. The full per-library list for
the release build, with the licence each library's POM declares, is in [DEPENDENCY_LICENSES.md](DEPENDENCY_LICENSES.md)
(190 libraries; generated by the "Dependency licence report" workflow). The component-by-component review notes are kept in the
development repository.

## Licence texts kept in this repository

- [licenses/Inter-OFL-1.1.txt](licenses/Inter-OFL-1.1.txt) and [licenses/Outfit-OFL-1.1.txt](licenses/Outfit-OFL-1.1.txt):
  the fonts' own licence files, copied unchanged from their upstream repositories.
- [licenses/Material-Icons-Apache-2.0.txt](licenses/Material-Icons-Apache-2.0.txt): the LICENSE file of
  google/material-design-icons (Apache License, Version 2.0), copied unchanged.
- [licenses/MIT-components.txt](licenses/MIT-components.txt): the MIT permission notice with the copyright line of every
  MIT component below.

The Apache-2.0 libraries are covered by the standard Apache License, Version 2.0 text (the file above is that text).

## Build tooling

The Gradle wrapper files (`gradlew`, `gradlew.bat`, `gradle/wrapper/gradle-wrapper.jar`) are Gradle's, under the Apache
License, Version 2.0 (the notice is in the scripts' headers). The jar's SHA-256 matches the wrapper JAR checksum Gradle
publishes for its 8.14.x releases; the build itself downloads Gradle 9.8.1. The Android Gradle Plugin, Kotlin compiler and
KSP are build tools and are not part of the APK.

## Icons

All 32 icons in `ui/icons/AppIcons.kt` use the path data of the "materialicons" (filled) set of
https://github.com/google/material-design-icons (Material Design icons by Google, Apache License, Version 2.0). 16 of them
matched that repository from the start; the other 16 (CalendarMonth, Search, Contrast, Palette, Storage, AutoAwesome,
Science, Tune, Person, Info, History, PlayCircle, PhotoCamera, Mic, Description and Draft) were replaced in October 2026
with the repository's own path data because their earlier path data could not be traced to a source. The Draft glyph is
Material's "edit_note" (Material Icons has no "draft" icon). The Apache-2.0 text is in
[licenses/Material-Icons-Apache-2.0.txt](licenses/Material-Icons-Apache-2.0.txt).

## Artwork in the README

`.github/hero.png`, `.github/showcase.png` and `.github/badge_obtainium.png` are original illustrations drawn for this
project in HTML and CSS and rendered with Chromium (`docs/art/`, run `python3 docs/art/render.py`). They use the app's own
colours, the bundled Inter and Outfit fonts (SIL OFL 1.1) and no third-party logos or photographs. They are illustrations,
not screenshots, and say so on the image. The badge is a plain text badge and does not use Obtainium's name as a logo or
its artwork; Obtainium (https://github.com/ImranR98/Obtainium, GPL-3.0) publishes no terms for reusing its own badge, so
its badge is not used.
