*copy features from https://github.com/Cocolalilal/LastChat 

. Advanced AI Chat
- Chat history and conversation management
- Edit, regenerate, continue, stop and retry responses
- Retry with another model
- Message branching
- Pin, archive and search conversations

2. Persistent AI Memory
- RAG-based memory retrieval
- Semantic memory search
- Automatic context retrieval
- View, edit and delete saved memories
- Global and conversation-specific memory

3. Provider & Model Management
- Multiple AI providers
- Custom OpenAI-compatible endpoints
- Automatic model discovery and manual model entry
- Per-model parameters
- Model selection and switching per conversation
- API connection testing
- Multiple Api keys per provider
- If one api token limit reached it'll use other saved api keys if all api key of current provider limit reached it'll try to switch between saved ai providers

4. Multimodal Chat
- Multiple image attachments
- PDF and document uploads
- File previews
- Document Q&A
- Audio input and transcription
- Video understanding where supported

5. Web Search
- Conversation-level search toggle
- Search results with citations
- Source links
- Source-grounded follow-up questions

6. Custom AI Assistants
- Custom system instructions
- Model and parameter preferences
- Reusable assistant profiles
- Study, research and writing presets
- Import/export assistant configurations

7. Study Mode
- Explain concepts at adjustable difficulty levels

8. Quiz Generator
- Generate questions from notes, PDFs and study materials

9. Note Assistant
- Summarize, rewrite, improve and organize notes

10. PDF Assistant
- Query, summarize and extract information from academic documents

11. Revision Assistant
- Generate revision plans based on syllabus and exam dates

12. Timetable Assistant
- Understand schedules and organize study time

13. Attendance Assistant
- Analyze attendance, identify shortages and answer attendance-related questions

14. Vault Integration
- Retrieve information from selected notes, folders and documents

15. Context-Aware AI
- Access selected attendance, timetable, tasks, reminders and calendar data with explicit user permission

15. Per provider token usage statistics
