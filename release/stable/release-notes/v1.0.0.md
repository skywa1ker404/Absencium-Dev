## Absencium 1.0.0

First stable release of Absencium, a student companion for Android: attendance, missed-class notes, calendar and exam countdown, with optional AI help you set up yourself.

**Requires Android 8.0 (API 26) or newer.** This is a young app. Back up from **Settings → Storage & Data** before you rely on it.

### What is in it
- Home, Attendance (calendar, timetable, holidays, exams) and Vault (notes by subject, photos, drafts, guide PDFs).
- Search across notes, PDFs and exams.
- Optional AI providers: OpenAI, Anthropic Claude, Google Gemini, OpenRouter, Groq, Ollama and a custom endpoint, with your own key. Nothing is sent anywhere until you set one up.
- Themes (Monet on Android 12+, 21 colour schemes), light and dark modes, optional Liquid Glass with a Performance mode.
- Backup and restore, an in-app changelog and **About → Legal → Open-source licences**.

### Not in this release
Reminders and notifications, home-screen widgets, several API keys per AI provider.
